
# Project Plan - A Beginner's Guide to Git Commands

## Project Goal

Our goal is to create a simple guide that helps beginners understand Git, set it up, and learn how to use basic Git commands.

## Guide Outline

### Part 1: Introduction to Git
- What Git is
- Why Git is useful
- How to install Git
- How to configure Git for the first time

### Part 2: Basic Git Commands
- git init
- git status
- git add
- git commit
- git push
- git pull
- Simple examples of how to use these commands
